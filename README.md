# 🏦 LoanGuard AI — Bank Loan Approval Prediction

> An AI-powered web application that predicts whether a loan application is likely to be **Approved** or **Rejected** using Machine Learning and provides an explanation of the factors influencing the prediction.

---

## 📌 Overview

**LoanGuard AI** is a Machine Learning-based Bank Loan Approval Prediction System developed using **Python, Scikit-learn, Flask, HTML, CSS, and JavaScript**.

The system analyzes an applicant's:

- Personal information
- Employment information
- Financial information
- Loan details
- Credit information
- Previous loan history

and uses a trained **Random Forest Classifier** to predict the loan status.

The application also integrates **SHAP (SHapley Additive exPlanations)** to provide an explanation of the major factors that influenced an individual prediction.

---

## 🎯 Project Objectives

The main objectives of LoanGuard AI are:

- Predict loan approval using Machine Learning.
- Analyze important financial and credit-related factors.
- Compare different Machine Learning algorithms.
- Provide an easy-to-use web interface.
- Display the probability of loan approval.
- Explain the major factors influencing each prediction using SHAP.
- Deploy the Machine Learning model as a web application.
